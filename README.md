# Flower Classification with CNN

Proyek ini merupakan implementasi model klasifikasi gambar bunga menggunakan Convolutional Neural Network (CNN) dengan TensorFlow dan Keras. Dataset yang digunakan adalah **Flowers Recognition** dari Kaggle.

## Struktur Program

1. **Import Library**
2. **Data Preparation**
3. **Data Loading**
4. **Data Preprocessing**
5. **Split Dataset**
6. **Modeling (CNN)**
7. **Evaluasi dan Visualisasi**
8. **Model Conversion** ke:
   - SavedModel
   - TensorFlow Lite (.tflite)
   - TensorFlow.js (.json)
